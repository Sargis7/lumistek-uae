# Lumistek — лендинг для ОАЭ (арабский + английский)

Одностраничный сайт компании **Lumistek** — производителя премиальной
полиуретановой защитной плёнки (PPF) для автомобилей, производство в Южной
Корее. Эта версия предназначена для рынка **Объединённых Арабских Эмиратов**
и работает на двух языках: **арабском** и **английском**.

> Это версия для ОАЭ. Для России существует отдельный лендинг
> `lumistek-russia` — это другой проект, его трогать не нужно.

## Что лежит в папке

```
lumistek-uae/
├── index.html          ← сам сайт (структура и оформление)
├── README.md           ← этот файл с инструкцией
├── .nojekyll           ← служебный пустой файл, нужен для GitHub Pages
├── .gitignore          ← список файлов, которые не выкладываются в git
└── assets/
    └── js/
        ├── i18n.js     ← ВСЕ ТЕКСТЫ САЙТА. Правятся здесь.
        └── lang.js     ← механизм переключения языка. Трогать не нужно.
```

**Важно понимать разницу:**

| Файл | За что отвечает | Нужно ли править |
|---|---|---|
| `index.html` | Разметка: где какой блок, оформление, размеры | Почти никогда |
| `assets/js/i18n.js` | Тексты на арабском и английском | **Да, здесь и только здесь** |
| `assets/js/lang.js` | Как работает переключатель языка | Нет |

Фотографий, видео и логотипа в папке пока нет — их нужно положить рядом с
`index.html`. Список файлов и требования — в разделе
[«Как заменить фото и видео»](#как-заменить-фото-и-видео).

## Как открыть сайт

**Посмотреть на своём компьютере:** дважды щёлкните по файлу `index.html`.
Он откроется в браузере (Chrome, Safari, Edge — любой).

**Выложить в интернет:** см. раздел
[«Как выложить сайт в интернет»](#как-выложить-сайт-в-интернет-github-pages).

Ничего устанавливать и «собирать» не нужно — сайт состоит из готовых файлов.
Единственное, что требует интернета — шрифт Cairo и стили Tailwind,
они подгружаются автоматически. Без интернета сайт откроется, но выглядеть
будет проще.

## Как переключается язык

В шапке сайта есть переключатель **`AR | EN`** — небольшая «пилюля» из двух
сегментов.

- **Активный язык** залит бирюзовым цветом (`#1cb0c6`) с белым текстом.
- **Неактивный** — серый, без заливки.
- Страницу **не нужно перезагружать** — текст меняется мгновенно.

Где находится переключатель:

- на **компьютере** — справа в шапке, рядом с кнопкой телефона;
- на **телефоне** — в шапке рядом с кнопкой меню (☰);
- в **открытом мобильном меню** — отдельный, более крупный, под кнопкой телефона.

**Как запоминается выбор.** Когда посетитель нажимает `AR` или `EN`, выбор
сохраняется в его браузере (в `localStorage` под именем `lumistek_ae_lang`).
При следующем визите сайт откроется на том же языке. Если посетитель заходит
впервые, сайт открывается на **арабском** — это язык по умолчанию.

**Что происходит с оформлением.** Арабский читается справа налево, английский —
слева направо. При переключении на `EN` сайт сам разворачивается: меню, блоки,
подвал и стрелки слайдера зеркалятся. Это уже настроено, вмешиваться не нужно.

## Как поменять тексты

**Все тексты сайта лежат в одном файле: `assets/js/i18n.js`.**
Это единственное место, где нужно что-то менять.

Откройте его любым текстовым редактором — подойдёт «Блокнот», но удобнее
[Notepad++](https://notepad-plus-plus.org/) или [VS Code](https://code.visualstudio.com/).

### Как устроен файл

Внутри два больших блока — арабский и английский:

```js
window.LUMISTEK_I18N = {
    ar: {                              // ← арабский
        "nav.about": "عن الشركة",
        "hero.ctaBook": "احجز الآن",
        ...
    },
    en: {                              // ← английский
        "nav.about": "About Us",
        "hero.ctaBook": "Book Now",
        ...
    }
};
```

Каждая строка — это **ключ** (слева, в кавычках) и **текст** (справа):

```
"nav.about": "عن الشركة",
 ─────────    ──────────
   ключ         текст
```

**Меняйте только текст справа от двоеточия.** Ключ трогать нельзя — по нему
сайт находит, куда подставить текст.

### Поиск нужного текста

Самый простой способ: нажмите `Ctrl+F` и введите фрагмент текста, который
видите на сайте. Например, чтобы поменять кнопку «Book Now», ищите `Book Now`.

Если хотите понять по ключу, где это находится на сайте:

| Начало ключа | Что это |
|---|---|
| `meta.*` | Заголовок вкладки браузера и описание для поисковиков |
| `nav.*` | Пункты меню |
| `hero.*` | Первый экран (крупный заголовок LUMISTEK, подзаголовок, кнопки) |
| `about.*` | Блок «О компании» и его 5 карточек |
| `products.*` | Заголовок каталога, сноска, кнопки на карточках |
| `price.*` | Подписи к ценам («Цена за рулон», «Цена за метр») |
| `p1.*` … `p10.*` | Товары по порядку: 1-й, 2-й, … 10-й |
| `gallery.*` | Галерея работ и подсказка «смахните» |
| `footer.*` | Подвал: описание компании, города, адреса, копирайт |
| `cookie.*` | Всплывающая плашка про cookie-файлы |
| `lead.*` | Форма заявки: заголовок, подписи, подсказки в полях |
| `privacy.*` | Модальное окно с политикой конфиденциальности |

Внутри каждой карточки товара ключи такие:

```
"p2.name":       "Lumistek WINDSHIELD",            ← название
"p2.type":       "حماية الزجاج الأمامي",            ← тип/подзаголовок
"p2.desc":       "فيلم بولي يوريثان شفاف...",       ← описание
"p2.rollPrice":  "4,200 د.إ",                      ← цена за рулон
"p2.meterPrice": "280 د.إ",                        ← цена за метр
"p2.alt":        "Lumistek WINDSHIELD PROTECTION",  ← подпись для незрячих
```

### Правила, которые важно соблюдать

1. **Меняйте текст и в `ar`, и в `en`.** Если поменять только в одном блоке —
   на втором языке останется старая версия.
2. **Текст всегда в двойных кавычках** `"..."`.
3. **Запятая в конце строки обязательна.** Это самая частая ошибка — если
   её убрать, перестанет работать весь словарь.
4. **Кавычки внутри текста** экранируются обратным слешем: `"вот так"`.
5. **Перенос строки внутри текста** записывается как `<br>`. Такие тексты
   помечены в `index.html` атрибутом `data-i18n-html` — в них можно
   использовать `<br>` и `<strong>жирный</strong>`.

### Если что-то сломалось

Признак ошибки: на сайте вместо текстов остались ключи вида `nav.about`,
или страница вообще не реагирует на переключатель.

Что делать: проверьте запятые в конце строк и парность кавычек. Удобно
сравнить с резервной копией — поэтому **перед правкой сохраните копию файла**
(например, `i18n.backup.js`).

## Как заменить фото и видео

Все изображения и видео лежат **в той же папке, что и `index.html`** (не в
`assets`). Имена файлов менять нельзя — сайт ищет их по этим именам.
Меняйте сами файлы, оставляя имя прежним.

### Список файлов

| Имя файла | Что это | Рекомендуемый размер |
|---|---|---|
| `logo.png` | Логотип LUMISTEK в шапке и подвале | PNG с прозрачным фоном, высота 200–400 px |
| `bg-video.mp4` | Фоновое видео на первом экране | 1920×1080, до 10 МБ, без звука |
| `product-1.jpg` … `product-10.jpg` | 10 фотографий товаров по порядку | **1000×1000 px**, до 300 КБ каждая |
| `gallery-1.jpg` … `gallery-5.jpg` | 5 фотографий в галерее работ | **800×1000 px** (вертикальные, 4:5), до 300 КБ каждая |

Порядок товаров соответствует нумерации в словаре: `product-1.jpg` — это
товар с ключами `p1.*`, `product-2.jpg` — `p2.*` и так далее.

### Требования к файлам

**Общие правила:**

- Формат фото — **JPG** (`.jpg`), логотип — **PNG** (`.png`),
  видео — **MP4** (`.mp4`, кодек H.264).
- **Вес критичен.** Каждый лишний мегабайт замедляет сайт, особенно на
  мобильном интернете. Старайтесь держать фото до 300 КБ.
- Имя файла — **только латиница, строчные буквы, без пробелов**.
  `Product 1.JPG` не подойдёт, нужно `product-1.jpg`.
- Расширение тоже важно: `.jpeg` вместо `.jpg` сайт не найдёт.

**Про фоновое видео:** оно проигрывается без звука и зациклено. Сделайте его
коротким (10–20 секунд) и хорошо сжатым. Если видео нет — уберите строку
`<source src="bg-video.mp4" ...>` в `index.html`, останется тёмный фон.

**Как сжать фото** (если файлы слишком тяжёлые):

- онлайн: [squoosh.app](https://squoosh.app/) — перетащите фото, выставьте
  качество 75–80 %, скачайте;
- или откройте фото в любом редакторе и «Сохранить для веба».

### Замена пошагово

1. Подготовьте новые файлы и переименуйте их точно как в таблице выше.
2. Скопируйте их в папку `lumistek-uae`, заменив старые.
3. Обновите страницу в браузере. Если фото не поменялось — обновите
   с очисткой кэша: `Ctrl+F5` (Windows) или `Cmd+Shift+R` (Mac).

## Как поменять цены

Цены находятся в словаре `assets/js/i18n.js`, в ключах `*.rollPrice`
(за рулон) и `*.meterPrice` (за метр). Например, для второго товара:

```js
// арабский
"p2.rollPrice":  "4,200 د.إ",
"p2.meterPrice": "280 د.إ",

// английский
"p2.rollPrice":  "AED 4,200",
"p2.meterPrice": "AED 280",
```

Обратите внимание: в арабском цена пишется как `4,200 د.إ` (сумма, потом
обозначение дирхама), в английском — `AED 4,200` (обозначение, потом сумма).
Это принятый порядок в каждом языке, лучше его сохранять.

Если цена «по запросу», в арабском стоит `حسب الطلب`, в английском —
`On request`.

**Текст подписи** («Цена за рулон (1.52×15 м)» / «Roll price (1.52x15 m)»)
меняется в ключах `price.rollLabel` и `price.meterLabel` — он общий для
всех товаров.

## Как поменять контакты и адреса

### Телефоны

Телефоны вписаны **напрямую в `index.html`**, а не в словарь, потому что это
не текст для перевода. Их нужно менять в нескольких местах — найдите по
`Ctrl+F` номер, который хотите заменить.

Разметка выглядит так:

```html
<a href="tel:+79917184442" dir="ltr" class="...">
    +7 (991) 718-44-42
</a>
```

Здесь **два места**: в `href="tel:..."` — номер без пробелов и скобок
(по нему совершается звонок), и между тегами — как номер выглядит на экране.

> **Внимание.** В текущей версии в подвале остались **российские и армянский
> номера** из исходного файла: `+7 (991) 718-44-42`, `+7 (937) 340-10-24`,
> `+7 (995) 832-08-52`, и у Аджмана — `+374 33 044 410`. Для сайта ОАЭ это,
> скорее всего, заглушки. **Их нужно заменить на реальные номера клиента.**

### Города и адреса

Названия городов и адреса — в словаре, ключи `footer.*`:

```js
"footer.dubai":        "دبي",                    // Дубай
"footer.dubaiAddr":    "شارع الشيخ زايد<br>مركز التجارة",
"footer.abudhabi":     "أبوظبي",                 // Абу-Даби
"footer.abudhabiAddr": "جزيرة الريم<br>برج الأعمال",
"footer.sharjah":      "الشارقة",                // Шарджа
"footer.sharjahAddr":  "المنطقة الصناعية<br>مجمع الشركات",
"footer.ajman":        "عجمان",                  // Аджман
"footer.ajmanAddr":    "شارع الشيخ عمار<br>&nbsp;",
```

`<br>` здесь означает перенос строки — так адрес занимает две строки.
В английском блоке те же ключи содержат английские названия.

### Ссылки на соцсети

Ссылки на Telegram и YouTube находятся в `index.html`. Найдите `t.me/` и
`youtube.com` через `Ctrl+F` и подставьте нужные адреса.

## Как выложить сайт в интернет (GitHub Pages)

Сайт — это обычные статические файлы, поэтому его можно бесплатно
опубликовать через **GitHub Pages**.

### Способ 1: через сайт GitHub (без программ)

1. Зайдите на [github.com](https://github.com/) и войдите в аккаунт
   (если его нет — зарегистрируйтесь, это бесплатно).
2. Нажмите **New repository**. Дайте имя, например `lumistek-uae`.
   Тип — **Public** (для бесплатного Pages это обязательно).
   Нажмите **Create repository**.
3. На странице репозитория нажмите **uploading an existing file**
   (или «Add file» → «Upload files»).
4. Перетащите **все** файлы и папки из `lumistek-uae`:
   `index.html`, `README.md`, `.nojekyll`, `.gitignore`, папку `assets`,
   а также все фото и видео.
   > Папку `assets` перетаскивайте целиком — вместе с `js/i18n.js` и `js/lang.js`.
5. Нажмите **Commit changes**.
6. Откройте **Settings** → в левом меню **Pages**.
7. В разделе **Branch** выберите `main` и папку `/ (root)`. Нажмите **Save**.
8. Через 1–2 минуты сайт будет доступен по адресу:
   `https://ВАШ_ЛОГИН.github.io/ИМЯ_РЕПОЗИТОРИЯ/`

### Способ 2: через командную строку

Если у вас установлен git:

```bash
cd lumistek-uae
git init
git add .
git commit -m "Lumistek UAE landing"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/lumistek-uae.git
git push -u origin main
```

Затем включите Pages: **Settings → Pages → Branch: main, / (root) → Save**.

### Как обновлять сайт после публикации

Изменения, загруженные в репозиторий, появляются на сайте автоматически
через 1–2 минуты. Пересобирать ничего не нужно.

**Как заменить файл без программ:** откройте репозиторий на GitHub →
щелкните по нужному файлу → значок карандаша (или «Upload files») →
загрузите новый файл с тем же именем → **Commit changes**.

### Зачем нужен файл .nojekyll

GitHub Pages по умолчанию прогоняет файлы через обработчик Jekyll, который
может проигнорировать файлы и папки, начинающиеся с подчёркивания или точки.
Пустой файл `.nojekyll` отключает эту обработку. Файл пустой — это нормально,
в нём не должно быть ни одной буквы. **Удалять его нельзя.**

### Свой домен

Если нужен адрес вида `lumistek.ae` вместо `github.io`:

1. Купите домен у любого регистратора.
2. В **Settings → Pages → Custom domain** впишите домен и сохраните.
3. У регистратора домена добавьте записи DNS, которые покажет GitHub.
4. Поставьте галочку **Enforce HTTPS**.

## Частые вопросы

**Сайт открылся, но фото не видно — серые квадраты.**
Значит, файлов нет в папке или имена написаны иначе (например, `Product-1.JPG`
вместо `product-1.jpg`). Проверьте имена и расширения — они должны совпадать
с таблицей в разделе [«Как заменить фото и видео»](#как-заменить-фото-и-видео).

**Поменял текст в `i18n.js`, а на сайте ничего не изменилось.**
Обновите страницу с очисткой кэша: `Ctrl+F5` (Windows) или `Cmd+Shift+R` (Mac).
Если не помогло — проверьте, сохранили ли вы файл и нет ли ошибки в кавычках
или запятых.

**На сайте вместо текста видны надписи вида `nav.about`.**
Это признак ошибки в `i18n.js`: скорее всего, потеряна запятая в конце строки
или незакрытая кавычка. Верните файл из резервной копии и правьте аккуратнее.

**Переключатель языка не работает, страница не реагирует.**
Убедитесь, что в `index.html` в самом начале подключены оба скрипта:
`assets/js/i18n.js` и `assets/js/lang.js`, и что папка `assets` загружена
на GitHub целиком.

**Как сделать, чтобы сайт открывался сразу на английском?**
В файле `assets/js/lang.js` найдите строку `var DEFAULT_LANG = "ar";`
и замените на `var DEFAULT_LANG = "en";`. Тогда для новых посетителей
сайт будет открываться на английском. Арабский останется доступен по кнопке.

**Нужно ли что-то устанавливать на компьютер?**
Нет. Сайт не требует сборки, компиляции или сервера. Достаточно браузера.

**Можно ли открыть сайт без интернета?**
Да, но шрифт Cairo и стили Tailwind подгружаются из интернета, поэтому
без сети оформление будет проще (стандартный шрифт, часть стилей пропадёт).
Для полноценной работы интернет нужен.

## Что нельзя делать

Чтобы сайт не сломался, избегайте следующего:

1. **Не переименовывайте файлы фото, видео и логотипа.** Сайт ищет их по
   строго определённым именам. Хотите другое имя — придётся править
   `index.html`, а это уже задача для разработчика.

2. **Не удаляйте `.nojekyll`, `.gitignore` и папку `assets`.** Без них сайт
   либо не опубликуется, либо останется без переводов.

3. **Не удаляйте атрибуты `data-i18n`, `data-i18n-html`, `data-i18n-placeholder`
   и подобные в `index.html`.** Именно по ним сайт понимает, куда подставлять
   тексты из словаря. Удалили атрибут — текст перестанет переводиться.

4. **Не меняйте ключи в `i18n.js`** (то, что слева от двоеточия). Меняйте
   только значения справа. Ключи — это адреса, по которым сайт ищет текст.

5. **Не трогайте файл `assets/js/lang.js`** без необходимости. Это механизм
   переключения языка и разворота страницы справа налево. Все тексты
   находятся в `i18n.js`, а не здесь.

6. **Не редактируйте `.jpg` или `.mp4` как текст.** Эти файлы открываются
   только графическими и видеоредакторами.

7. **Перед крупными правками делайте копию `i18n.js`.** Если что-то пойдёт
   не так, будет куда вернуться.

## Краткая шпаргалка

| Задача | Что открыть |
|---|---|
| Поменять любой текст | `assets/js/i18n.js` |
| Поменять цену | `assets/js/i18n.js`, ключи `*.rollPrice`, `*.meterPrice` |
| Поменять название города или адрес | `assets/js/i18n.js`, ключи `footer.*` |
| Поменять телефон | `index.html`, поиск по `tel:` |
| Поменять логотип | заменить файл `logo.png` |
| Поменять фото товара | заменить `product-1.jpg` … `product-10.jpg` |
| Поменять фото в галерее | заменить `gallery-1.jpg` … `gallery-5.jpg` |
| Поменять видео на первом экране | заменить `bg-video.mp4` |
| Язык по умолчанию | `assets/js/lang.js`, строка `DEFAULT_LANG` |
| Опубликовать сайт | GitHub → Settings → Pages → main / root |
