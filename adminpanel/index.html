Подключение к GitHub

Панель сохраняет изменения прямо в репозиторий сайта. После этого Railway сам пересобирает сайт — обычно за 1–2 минуты.

Как получить токен

  1. Откройте github.com/settings/personal-access-tokens/new
  2. Token name — например lumistek-admin
  3. Expiration — поставьте «No expiration», иначе панель перестанет работать
  4. Repository access — «Only select repositories» → выберите репозиторий сайта
  5. Permissions → «Repository permissions» → Contents → Read and write
  6. Нажмите Generate token и скопируйте строку, начинающуюся с github_pat_…

Токен хранится только в этом браузере (localStorage) и отправляется напрямую в GitHub. Никуда больше он не уходит. Если сядете за другой компьютер — впишите токен там заново.
